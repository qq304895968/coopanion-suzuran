# seedvc-cover —— 一条命令，把一首歌换成某个角色的声音

给 AI 用的翻唱插件。零样本，**不用训练模型**。

---

## 它是干什么的

你手上有一段角色的干净音频，和一首想让她唱的歌。

```
一首歌 + 30 秒参考 → 一条命令 → 她唱完了
```

中间要做的事——分离人声、定变调、换嗓、伴奏跟调、混音、归一——它全做了，每一步带验收。

## 为什么是 Seed-VC

因为这活最贵的一步是「拿到这个角色的模型」。

RVC 要训几个小时，几百条素材，还得调参数。Seed-VC 不要：30 秒素材丢进去就能唱。对一个第一次上手的账号，前者几乎等于做不到。

代价是精细度不如训好的模型。但对「先跑通」来说，这个代价值得付。

## 怎么用

```bash
bash scripts/cover.sh --song 你的歌.mp3 --out 成品.mp3
```

不给 `--ref` 就用插件自带的参考音色，装上就能听到东西。

要换成你自己的角色：

```bash
bash scripts/cover.sh --ref 你的参考30秒.wav --song 你的歌.mp3 --out 成品.mp3
```

## 它不替你做的判断

**参考音频好不好，决定这台上限。** 脚本能自动去搜、去切、去拼，但它看不出三件事：

- 这段是不是同一个角色（多角色视频里混着别人的声音）
- 有没有 BGM 底噪
- 语气会不会太极端（生日语音里的辱骂、战斗喊叫，拿来当参考，唱出来那首歌就带火气）

所以它能做的是把「找素材」这一步从半小时压到五分钟，不能替你听。

## 变调是每次量的，不是背下来的

说明书里没有「女声用多少」这种表。只有算法和四条自查：

两个基频中位数相减 → 算半音 → 拿 10 秒试唱量电音 → 最后一条是**跟着伴奏唱不跑调**。

数字对上了还跑调，一定是参考量错了。

## 它给的是尺子，不是答案

`steps`、`cfg`、`vocal-db` 这些，说明书都写了「为什么是这个值」和「怎么判断改对没改对」。

觉得哪个没道理，改就是了。改完把理由写在旁边——下一个用的人会看到。

## 边界

插件包里只有我们自己的脚本和一份参考音频，**不含任何别人的代码或模型**。

Seed-VC 是 GPL-3.0，RVC 和 pymss 是 MIT，得你自己装，地址都在 SKILL.md 里。
