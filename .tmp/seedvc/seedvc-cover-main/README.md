# seedvc-cover

**一条命令，把一首歌换成某个角色的声音。** 零样本，不用训练模型。

给 AI 用的翻唱插件。装进 DSH 之后，说一句「用这个把这首歌唱成 XX 的声音」就行。

---

## 它是干什么的

你手上有一段角色的干净音频，和一首想让她唱的歌。

```
一首歌 + 30 秒参考 → 一条命令 → 她唱完了
```

中间要做的事——分离人声、定变调、换嗓、伴奏跟调、混音、归一——它全做了，每一步带验收。

```bash
bash scripts/cover.sh --song 歌.mp3 --out 成品.mp3
```

不给 `--ref` 就用插件自带的参考音色，装上就能听到东西。

换成你自己的角色：

```bash
bash scripts/cover.sh --ref 你的参考30秒.wav --song 你的歌.mp3 --out 成品.mp3
```

## 为什么是 Seed-VC

因为这活最贵的一步是「拿到这个角色的模型」。

RVC 要训几个小时，几百条素材，还得调参数。Seed-VC 不要：30 秒素材丢进去就能唱。对一个第一次上手的账号，前者几乎等于做不到。

代价是精细度不如训好的模型。但对「先跑通」来说，这个代价值得付。

## 跑起来要什么

| 项 | 最低 |
|---|---|
| 显卡 | NVIDIA，**12 GB 显存**（卡在分离那步，实测峰值 8.9 GB） |
| 内存 | 16 GB |
| 硬盘 | 25 GB 空闲 |
| Python | 3.10+ |
| ffmpeg | 近期任意版本 |

分步实测：分离 8.9 GB、Seed-VC 3.1 GB、混音纯 CPU。

**8 GB 卡跑不了分离**，但可以手工分好后用 `--no-sep`；**没有显卡也能出活**，加 `--device cpu`，慢，但能出。

依赖的引擎（Seed-VC / RVC / pymss）**需要你自己装**，地址在 [SKILL.md](SKILL.md) 里。这个仓库只包含我们自己的脚本和一份参考音频。

## 它不替你做的判断

参考音频决定这台上限。脚本能自动搜、切、拼，但看不出三件事：

- 这段是不是同一个角色（多角色视频里混着别人的声音）
- 有没有 BGM 底噪
- 语气会不会太极端（生日语音里的辱骂、战斗喊叫，拿来当参考，唱出来那首歌就带火气）

垃圾进去，垃圾出来，这条在哪都一样。

## 它给的是尺子，不是答案

`--shift`、`--steps`、`--cfg`、`--vocal-db` 这些参数，说明书里都写了「为什么是这个值」和「怎么判断改对没改对」。

觉得哪个没道理，改就是了。改完把理由写在旁边——下一个用的人会看到。
