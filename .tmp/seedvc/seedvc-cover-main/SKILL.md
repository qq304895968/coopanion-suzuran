# skill: seedvc-cover —— 一条命令，把一首歌换成某个角色的声音

零样本。**不用训练模型**，给它 30 秒该角色的干净音频，它就能唱。
这条线的全部价值在「判断」不在「参数」——每个数字都要自己量，别抄。

想改成 RVC、想加和声、想换混音链，都可以。每节下面都写了「为什么是这个值」，知道原因你就知道改了会怎样。

---

## 一、装

**下面这些都是别人的开源项目，得你自己装。**

这个插件包里只有我们自己的脚本和一份参考音频，**不带任何别人的代码或模型**。
原因：带进来就变成分发，而 Seed-VC 是 GPL-3.0，一打包整个插件都得跟着 GPL。
所以说明书只给地址，装不装、装哪、怎么装，你决定。

每一条下面都写了「为什么是这个值」，你想换实现也可以换——前后步骤是通用的。

### 1. 系统依赖

```bash
python --version     # 3.10+
ffmpeg -version      # 任意近期版本
```

### 2. Seed-VC（换嗓引擎）

```bash
git clone https://github.com/Plachta/Seed-VC
cd Seed-VC
python -m venv .venv
.venv/bin/pip install -r requirements.txt     # Windows: .venv\Scripts\pip
```

首次运行会自动从 HuggingFace 下权重。国内先设代理或镜像：

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

### 3. 分离人声（可选但强烈建议）

```bash
git clone https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI
```

模型 `1_HP-UVR.pth` 会自动从 modelscope 下，不用手动找。
自动下载失败的话，去 modelscope 搜 `UVR` 手动下，放到仓库根目录就行。

### 4. 本插件的 Python 依赖

```bash
pip install numpy librosa
```

`librosa` 只用来量音高。不想装就每次手动给 `--shift`。

### 5. 最低电脑配置

| 项 | 最低 | 说明 |
|---|---|---|
| 显卡 | NVIDIA，**12 GB 显存** | 卡在分离那一步；Seed-VC 自己只要 3.1 GB |
| 内存 | **16 GB** | 分离和混音时 CPU 侧的开销 |
| 硬盘 | **25 GB 空闲** | 见下面的账 |
| CPU | 4 核 | 没显卡的时候全靠它 |
| Python | 3.10+ | |
| 系统 | Windows 10/11 或 Linux | 两种都跑过 |
| ffmpeg | 近期任意版本 | |

**磁盘这 25 GB 花在哪**（实测量过）：

| 内容 | 大小 |
|---|---|
| Seed-VC 的 venv（大头是 PyTorch CUDA） | 6.3 GB |
| Seed-VC 模型权重 | 1.4 GB |
| 分离模型 `1_HP-UVR` | 约 0.1 GB |
| 一首 4 分钟歌的中间 wav | 0.5~1 GB |

装完实际占五六 GB，剩下的留给中间文件和系统。

**分步显存峰值**（NVIDIA 卡实测）：分离 8.9 GB、Seed-VC 3.1 GB、混音 0。

**8 GB 卡跑不了分离**，但可以手工把歌分离好，用 `--no-sep --vocal 人声.wav` —— Seed-VC 那 3 GB 是跑得动的。

**完全没有显卡也能出活**：加 `--device cpu`。会明显变慢（估计慢 20~50 倍，没实测过，一首歌从几十秒变成几十分钟），但能出。

## 二、跑

```bash
bash scripts/cover.sh --song 歌.mp3 --out 成品.mp3                  # 用自带音色
bash scripts/cover.sh --ref 你的参考.wav --song 歌.mp3 --out 成品.mp3   # 换角色
```

**插件里自带一份 42 秒的预设参考**（`assets/ref_default.wav`），不给 `--ref` 就用它。
装上就能跑，不需要先找素材。

想换成别的角色：准备 30 秒干净音频用 `--ref` 指过去，或者用下面的 `find_ref.py` 自动找。

它会依次做完：分离 → 定调 → 换嗓 → 伴奏跟调 → 混音 → 出 mp3 → 验收。

出的东西放在 `--out`。中间文件默认清掉，想留着调试就加 `--keep`。

## 三、参考音频（这一步决定上限）

**换嗓的上限是参考音频决定的，不是模型决定的。** 参考差，后面怎么调都救不回来。

### 优先自己手动提

| 来源 | 干净度 | 说明 |
|---|---|---|
| **游戏资源包解包** | 最好 | 原始语音文件，无 BGM、无混响 |
| **官方语音合集** | 好 | 多数没 BGM，挑段即可 |
| **动画/游戏实况录像** | 一般 | 必须分离 + 去混响，还带环境音 |

要求：**30 秒左右、单声道、16k 以上、没有削波**。

### 只有视频时的兜底脚本

```bash
python scripts/find_ref.py --char 角色名 --out ref30.wav          # 搜 B 站、下载、切段、拼接
python scripts/find_ref.py --char 角色名 --out ref30.wav --sep    # 顺手分离人声
```

**它给的是候选，不是答案。** 三件事脚本判断不了，必须自己听：

- 混进别的角色或旁白（多角色视频靠标题分不出来）
- BGM 底噪（全程有音乐时检测不到静音段，脚本会退化成固定长度切并在日志里警告）
- 语气太极端（生日辱骂语音、战斗喊叫，拿来当参考会把整首歌的语感带偏）

## 四、参数怎么定（别抄，要量）

### `--shift`：变调半音

**这是最容易做错的一个。**

不给就自动量：`pitch_match.py` 分别算源人声和参考的基频中位数，`变调 = 12×log2(参考÷源)` 取整。

怎么看它量得对不对：

- **两个中位之比接近 1.5 / 2.0 / 0.5** → 音高跟踪器跳到二次谐波上了，脚本会告警，人工复核
- **能用升调就别用降调** → 每降一个半音梳齿深一点，降满八度就别指望不电
- **量出来是 0 也要试** → 拿 10 秒试唱，听跑不跑调
- **最终判据是跟着伴奏唱不跑调** → 数字对上了还跑调，一定是参考量错了

### `--steps`：扩散步数

默认 30。往上更细更慢，**加到听不出区别就停**，别为了心安堆到 100。

### `--cfg`：贴参考的程度

默认 0.7。往高更贴参考但容易僵，往低更自然但不像。这个和 `--steps` 一样，用耳朵定，不是用数字定。

### `--vocal-db`：人声比伴奏高多少 dB

默认 +2。**高太多像配乐朗诵，低太多被埋。** 1~3 是正常区间，具体落哪试听决定。

脚本按「正在发声那段的 RMS」对齐电平——不是整轨 RMS。整轨会被静音段稀释，量出来是错的。这是这条链上最容易犯的错。

### `--device`

`cuda` 默认。没显卡用 `cpu`，慢，但能出。

## 五、每一步不过怎么办

| 步骤 | 判据 | 不过 |
|---|---|---|
| 分离 | 伴奏里没人声、人声里没乐器 | 换模型，或者手工分好走 `--no-sep` |
| 换嗓 | 像不像那个角色 | 先查参考，别先改参数 |
| 时长 | 成品和源差 < 1 秒 | 中间产物串了，或者分离吃掉了尾巴 |
| 响度 | −14 LUFS、−1 dBTP | 脚本已自动归一，不用管 |
| 电音 | 人声发沙、有金属感 | 变调降太多了，或者源本身质量差 |

## 六、踩过的坑

1. **参考音频混着 BGM** —— 换出来的人声里会一直有那层音乐，怎么混都盖不掉
2. **参考是说话不是唱** —— 量的基频是说话的，整首歌偏高或偏低
3. **伴奏没跟着变调** —— 人声对了，整首歌跑调。脚本会自动跟，手工改的时候别忘了
4. **预先把人声降调再送进换嗓** —— 梳齿提前做进去了，后面补不回来
5. **只信分数选结果** —— 声纹相似度只量像不像，量不出好不好听
6. **短片段下结论** —— 10 秒样片的分数天然偏低，别拿它判死刑

## 七、想改的话

这插件故意不封死，三处最常见：

**换引擎**（想用 RVC）：把 `cover.sh` 第 3 步换成 RVC 推理就行，前后步骤都不用动——分离、定调、混音是通用的。

**加和声**：第 5 步前多一条轨迹，同样走一次 Seed-VC，混音时压到 −4~−4.5 dB。压太轻等于没做。

**改混音链**：`mix_two.py` 只管电平对齐，不加 EQ 和混响。要加就在 `ffmpeg` 那条命令里塞滤镜。

**环境变量**（分离和换嗓不是同一个 Python 环境，这两条最容易卡）：

| 变量 | 默认 | 作用 |
|---|---|---|
| `SEEDVC_DIR` | `~/Seed-VC` | 换嗓引擎位置，换嗓用它自己的 `.venv` |
| `PY_SEP` | 自动找 rvc312 / RVC 的 venv | **分离**用的解释器，要装了 `av` 和 `torch` |
| `PY` | Seed-VC 的 python | 兜底 |
| `RVC_DIR` | `~/ai_cover/RVC` | 分离工具 pymss 的位置 |

分离报 `No module named 'av'` 就是这个原因：它拿了 Seed-VC 的 Python。
用 `PY_SEP=/你的/python bash scripts/cover.sh ...` 指定一个装好 pymss 环境的解释器。

**改判断**：每一步的判据在第五节，觉得哪个不合理就改，改完把为什么写在旁边——下一个用的人会看到。
