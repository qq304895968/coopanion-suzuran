# 铃兰 桌宠形象包（suzuran，四套服装）

《明日方舟》干员 **铃兰 / 丽萨**（`char_358_lisa`）的桌面宠物形象包，供 Coopanion
（`cortico-world-desktop-pet`）使用。一个包内含四套服装，可在设置界面的「服装」里切换。

| id | 服装 | 说明 |
| --- | --- | --- |
| `default` | 默认 | 白蓝连衣裙、蓝发带，提灯法杖 |
| `spring` | 春之颂 | 罗小黑战记联动，连帽春装，帽子上趴着一只黑猫 |
| `snow` | 雪霁 | EPOQUE 系列，振袖和红纸伞 |
| `wild` | 弃土花开 | 生命之地系列，探索者装束与太阳能法杖 |

## 来源与转换

- 模型来源：PRTS Wiki 干员页「干员模型」→ Spine 3.8 资源
  `https://torappu.prts.wiki/assets/char_spine/char_358_lisa/<skin>/front/`
- 每套衣服是独立的 Spine 模型：都摆到 **Idle 动画首帧**，按插槽颜色的透明度取每个部件的
  世界顶点与 UV，软件光栅化烘焙成 `tex/<服装>/` 里的贴图；骨骼层级保留为 `model.json`
  中该服装的 `deformers`（以骨骼原点为转轴的旋转）。
- 四套共用同一个比例（以最高的一套为准）和同一条地平线，换装不会忽大忽小。
- 运行时不依赖 Spine 运行时，也不联网。

## 文件

| 文件 | 说明 |
| --- | --- |
| `figure.json` | 清单（manifest 2 / api 2）：4 个服装选项 + 4 个预设、22 个词汇、气泡配色 |
| `figure.js` | 形象工厂 `createSuzuranBody`：按当前服装加载贴图、逐帧算骨骼角度并绘制；`setScheme(id)` 换装 |
| `model.json` | `looks.default/spring/snow/wild` 四套部件与变形器，以及每套的眼睛/嘴/闭眼/眩晕部件表 |
| `tex/<服装>/*.png` | 每套的部件贴图（3 px / 逻辑单位），共 416 张、约 5.7 MB |
| `thumbs/*.png` | 四套服装的缩略图 |

## 安装

```
D:\daily use\Coopanion\data\figures\suzuran\
```

保证 `...\figures\suzuran\figure.json` 存在，重新打开「设置 → 形象」即可看到「铃兰」，
在「服装」里选四套之一。

## 会做什么

- 待机：呼吸、头部随光标轻转、九条尾巴与头发摆动、耳朵轻抖、随机眨眼（默认 / 春之颂 /
  雪霁；弃土花开的脸在贴图里画死了深色眼窝，没有闭眼素材，这一套不眨眼）
- 走路 / 跑动：手臂与腿摆动；说话：嘴部轻微开合（春之颂有真正的张嘴贴图，其余用拉伸模拟）
- 表情：平静、开心、眨眼、喜欢、惊讶、害羞、难过、困、思考；默认装束眩晕时切到
  模型自带的 `F_Face_Stun_*` 转圈眼
- 坐、睡：低头、闭眼
