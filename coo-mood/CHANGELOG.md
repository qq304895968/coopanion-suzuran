## 0.2.0

- 修复：`desktop-pet.self` 的 `activity` / `figure` 等自身记录以前会落进通用的外部事件兜底，被当作用户消息，导致用户没回复也会走 Δ_对话（例如 23:34 的“普通闲聊 -1.1”）。现在这些记录一律忽略；通用兜底只收 message / speech / chat / msg 类事件，并排除 `desktop-pet` / `screen` / `mood` 来源。
- 浏览通道改为优先使用 `pet_say` 实际播放的表情标签（thinking / neutral 不再因为回复里引用了网页中的“垃圾话”而重扣），文字语气只做小幅修正；原因文案改为“看一眼后的表情与语气”。
- 新增情境问答（Galgame）子功能：`gal_start` 让模型按人设/记忆生成情境 + 问题 + A/B/C 三个选项，校验 delta -5..+5、一个最好一个最差一个中间。
- 显示复用桌面宠的 `pet_ask`：情境和问题放同一个气泡，三个选项变成 A/B/C 按钮；`allowOwnAnswer: false`，关闭/超时无惩罚。
- 插件通过 `desktop-pet.self` 的 ask 事件绑定本次提问，再用 `desktop-pet.answer` 的 index 把选择映射回 mood_delta，归入 Δ_对话 通道（受单日 ±20 上限与边际递减约束）。
- 触发：用户说“来个小故事 / 考考我 / 出个题”时由模型调 `gal_start(source="user")`；待机时低概率推 `mood.gal_hint`（每日自动 ≤2 次，心情 <30 或 >80 时概率 ×3）。
- 新增配置组「心情 · 小游戏」：启用开关、自动每日上限、待机分钟数、每分钟概率、极端心情加成、提示冷却、是否唤醒、进行中超时。
- 面板新增小游戏今日次数与进行中状态；`mood_status` 增加小游戏统计；环境提示词增加 `mood.gal` 段。

## 0.1.0

- World `mood`，契约 `cortico.api = 6`。
- 心情值 0–100：每日向中性锚点回归 + 一次高斯扰动；支持 config 里的回归比例、扰动标准差与极端值保护。
- 三条驱动通道：对话（自动词表估算，可选模型 `mood_feel` 自报）、浏览（监听「看一眼」`screen.shot`，模型也可 `mood_apply(source=browse)`）、搭理（长时间未互动扣分、回来加分、主动招呼等待窗）。
- 人设模板与系数：温柔/敏感、中性、乐观、悲观、傲娇、易怒；黏人/独立影响搭理通道；支持自定义中性锚点、正面/负面系数与人设补充。
- 单日各通道上限（对话 ±20、浏览 ±10、搭理 ±15）、合计 ±35、边际递减与接近上限时的二次衰减。
- 五个区间（critical_low / low / neutral / high / euphoric）：说法、想法、行为、话题、功能解锁与可用表情词全部映射。
- 情绪标签概率：基础 5×5 表 × 人设权重 × 用户语气，归一化；`mood_roll` 直接抽标签并给出可用的桌宠表情 / 动作词。
- 提示词：环境段常驻规则；每轮 `mood.snapshot`（piggyback）带上当前区间与思维方式；跨区间、每日结算、连续低落自救分别推 `mood.threshold` / `mood.daily_reset` / `mood.self_rescue`。
- 人设识别：面板按钮读取 `workspace/CONSTITUTION.md`，按关键词估模板、黏人程度、中性锚点与正负面系数，写成自定义配置。
- 面板：当前值 / 区间 / 今日通道 / 14 天结算 / 最近变化 / 人设识别 / 手动设值与重置。
- 数据：`<dataDir>/mood/state.json`，原子写入，坏文件挪到 `.corrupt-<时间戳>`；默认保留 30 天，最多 90 天。
- `pnpm smoke`：不依赖 vitest / esbuild 的核心冒烟；`pnpm test` 保留一个轻量模型测试文件。
